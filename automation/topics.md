## Themen-Auswahl-Logik (für generate.py)

Das Skript wählt das nächste Thema nach dieser Reihenfolge:

1. **Saisonal passend** (heute liegt im angegebenen Monat ±2 Wochen)
2. **Höchste Priorität** (P1 > P2 > P3)
3. **Status = `idea`** (nicht `drafting`, `pending-review` oder `published`)
4. **Erstes in der Liste**, falls Gleichstand

Nach Generierung wird der Status auf `drafting` gesetzt — nach Versand auf `pending-review`, nach Freigabe auf `published`.

Manuelle Überschreibung jederzeit möglich:
```bash
python3 generate.py --topic T-007
```
